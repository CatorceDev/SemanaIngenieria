# SemanaIngenieria

Proyecto desarrollado para la clase de Programación Web 2. Consiste en una landing page para la Semana de la Ingeniería de la FES Aragón, donde los usuarios pueden explorar el programa de conferencias, consultar detalles de cada evento y agregar entradas a un carrito de compras con una simulación del proceso de pago.

## Descripción del proyecto

Este proyecto busca recrear una experiencia de sitio web institucional y promocional para un evento académico y tecnológico. La aplicación presenta:

- Una sección principal con mensaje de bienvenida.
- Un programa de conferencias con información relevante.
- Tarjetas de cada charla con título, ponente, horario y precio.
- Carrito de compras para agregar y eliminar entradas.
- Simulación de compra con selección de banco y confirmación final.
- Diseño responsivo para escritorio y dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript vanilla
- Assets locales (imágenes, íconos y fuentes)

## Funcionalidades principales

- Visualización del programa del evento.
- Agregar conferencias al carrito de compras.
- Actualización automática del total y la cantidad de entradas.
- Eliminación individual o vaciado del carrito.
- Modal de compra para simular el pago por banco.
- Menú responsive y navegación con desplazamiento suave.

## Requisitos

- Un navegador moderno (Chrome, Edge, Firefox o Safari).
- Opcionalmente, un editor como VS Code con la extensión Live Server para visualizar el proyecto de forma más cómoda.

## Cómo ejecutar el proyecto

1. Clona este repositorio:

```bash
git clone https://github.com/CatorceDev/SemanaIngenieria.git
```

2. Entra a la carpeta del proyecto:

```bash
cd SemanaIngenieria
```

3. Abre el archivo `index.html` en tu navegador.

Si prefieres una mejor experiencia de desarrollo, puedes abrir la carpeta en VS Code y usar Live Server para ejecutar la página con recarga automática.

## Objetivo académico

Este proyecto fue desarrollado como ejercicio para practicar:

- Maquetado web con HTML y CSS.
- Manipulación del DOM con JavaScript.
- Diseño responsivo.
- Interacción de usuario en una aplicación front-end.
- Simulación de flujo de compra en una tienda de eventos.
